🐘 Resistive Sensing-Based Elephant Intrusion Detection System
📌 Overview

This project presents a Resistive Sensing-Based Framework for Real-Time Detection of Elephant Intrusions with Automated Deterrence. It is designed to reduce human–elephant conflicts by providing early detection and instant alerts when elephants cross protected boundaries such as farmlands or forest edges.

The system uses a resistive sensing wire to detect disturbances caused by large animals. When an elephant comes into contact with the sensing line, a change in resistance generates a voltage signal. This signal is processed by an ESP32 microcontroller, enabling real-time monitoring and response.

⚙️ Features
📡 Real-time intrusion detection
🔔 Instant alert system (buzzer + mobile notification)
🌐 IoT-based remote monitoring
⚡ Low power and cost-effective design
🛡️ Non-lethal automated deterrence system
📶 Wireless communication support
🧰 Technologies Used
ESP32 Microcontroller
Resistive Sensing Mechanism
IoT (Wi-Fi Communication)
Mobile Notification Integration
Embedded C / Arduino IDE
🔌 System Architecture
Sensing Unit – Detects resistance change when elephants interact with the wire
Processing Unit (ESP32) – Reads sensor data and analyzes intrusion
Alert System – Activates buzzer and sends mobile alerts
Deterrence Module – Generates sound to repel elephants
🚀 How It Works
The sensing wire is installed along boundaries.
When disturbed, resistance changes.
ESP32 detects voltage variation via ADC.
Intrusion is confirmed.
Alerts are triggered and deterrence activated.
